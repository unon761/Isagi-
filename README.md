# Isagi Bot — Pokémon GO Description Generator

A Telegram bot that turns Pokémon GO account screenshots into a formatted,
premium-style sale listing, using **only Groq** (a vision model for
OCR/stat extraction from the screenshots, and a text model for a short
grounded marketing paragraph).

## How it works

1. User sends one or more screenshots — they're queued in memory.
2. `/generate` runs each screenshot through Groq's vision model
   (`qwen/qwen3.6-27b`) with a strict prompt: extract only what's literally
   legible, and return `null` for anything unclear — **never guess**.
3. The per-image results are merged (first non-null value wins per field;
   Pokémon/item lists are deduplicated).
4. A short marketing paragraph is generated by a Groq text model
   (`llama-3.3-70b-versatile`), grounded only in the extracted data.
5. The rest of the listing (stats, Indian-style number formatting like
   `4,98,67,640`, section headers) is assembled deterministically in
   Python from the merged data — this avoids the model hallucinating
   numbers. Anything that couldn't be read from any screenshot is shown
   as "Not visible in screenshots" and listed in a note at the end,
   instead of being made up.

## Setup

```bash
cd isagi_bot
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Your `.env` file is already filled in with the token and key you provided.
**Important:** you pasted these credentials in plain text — since they've
now been exposed in a chat log, it's worth rotating (regenerating) both
the Telegram bot token (via @BotFather → `/revoke`) and the Groq API key
(console.groq.com → API Keys) once you're done testing, then updating
`.env` with the new values. Never commit `.env` to a public repo — the
included `.gitignore` already excludes it.

Run the bot:

```bash
python bot.py
```

## Commands

**Everyone**
- `/start` — welcome message + free trial balance
- `/help` — list commands
- `/balance` — coins, free trials, subscription status, queued screenshots
- `/pricing` — pricing and plans
- `/generate` — generate a description from queued screenshots (4 coins)
- `/clear` — clear queued screenshots

**Admin only** (Telegram user ID `7568676840`)
- `/addcoins <id> <amount>`
- `/removecoins <id> <amount>` (floors at 0)
- `/addsub <id> [plan]` — plan is one of `1day 3day 7day 15day 31day 365day` (default `31day`)
- `/removesub <id>`
- `/userinfo <id>`

## Economy

- New users get **3 free trial generations** (no coins needed).
- After that, each generation costs **4 coins**.
- An active subscription (granted via `/addsub`) makes generations unlimited
  and free for its duration.
- The admin account always generates for free.
- Balance is only deducted **after** a generation succeeds — a failed
  Groq call never costs the user coins or a trial.

## Notes on accuracy

The bot is deliberately conservative: if a stat, Pokémon, or item isn't
clearly readable in at least one of the screenshots you send, it will not
appear as a fabricated value — it's either shown as "Not visible in
screenshots" or omitted from a list, and flagged in a note at the end of
the listing. Sending clearer, more complete screenshots (account overview,
Pokémon box/rare list, and item/bag screens) produces a more complete
listing.
